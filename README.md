# bitwise_OPS
Hex->Dec->Bin visualization and Bitwise ops


INSTRUCTIONS

Actually it only works by terminal.

Just input:

1) An hex value with or without 0x0 notation. THIS WILL OUTPUT datatype, decimal and binary
2) An hex value followed by ~ or write literally "toggle" THIS WILL OUTPUT datatype, decimal and binary and inverted hex value
3) Two hex values with in the middle BITWISE logic operators and & or | xor ^ shift right >> shift left << . THIS WILL OUTPUT datatype, decimal and binary and result of operation
